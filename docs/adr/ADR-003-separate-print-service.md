# ADR-003: فصل خدمة توليد الطباعة وملفات PDF (Separate Print & PDF Generation Service)

- **الحالة (Status):** مقبول (Accepted)
- **التاريخ (Date):** 2026-10-11
- **أصحاب القرار (Decision Makers):** @djalle2004-eng
- **المشاورون (Consulted):** فريق هندسة النظم وإدارة جداول التوقيت

---

## 1. السياق والمشكلة (Context & Problem Statement)
توليد جداول التوقيت المطبوعة بصيغة PDF وقوائم الحصص يتم حاليًا داخل متصفح العميل عبر مكتبات ثقيلة مثل `@react-pdf/renderer` و`html2pdf.js` وPuppeteer في الخادم. ينتج عن هذا:
- استهلاك مرتفع للذاكرة والمعالج في جهاز المستخدم عند طباعة جداول الكلية بالكامل (أكثر من 300 أستاذ و190 فوجًا).
- تباين في مخرجات الطباعة ودقة الخطوط العربية بين المتصفحات وأنظمة التشغيل المختلفة.
- احتمالية حدوث تجمد (Browser Freeze) أو تعطل في عمليات الطباعة المجمعة.

## 2. المحركات المعمارية (Decision Drivers)
- دقة ومطابقة تامة لمخرجات الطباعة (Pixel-perfect & Vector-grade PDF).
- دعم كامل للخطوط العربية (Amiri, Cairo) مع التشكيل والمحاذاة الصحيحة (RTL shaping & HarfBuzz).
- عزل الحمل الحسابي الثقيل لإنشاء ملفات PDF المجمعة خارج دورة حياة خادم الـ API الرئيسي.

## 3. الخيارات المدروسة (Considered Options)
1. **الاستمرار على التوليد داخل المتصفح (Client-side Rendering):** تجربة سريعة للجداول الفردية، لكنها تفشل تمامًا في الطباعة المجمعة لأقسام كاملة.
2. **فصل خدمة طباعة مستقلة (Dedicated Headless Service / Microservice) (المعتمد):** خدمة خلفية خفيفة تعتمد على Playwright / Puppeteer أو محرك تجميع PDF منخفض المستوى مع قائمة انتظار مهام (Queue Worker).
3. **الاعتماد على خدمات سحابية خارجية (DocRaptor / CloudConvert):** مكلفة وتنتهك خصوصية البيانات الأكاديمية للمؤسسة.

## 4. القرار المعتمد (Decision Outcome)
عزل منطق رؤوس الطباعة وتنسيق الجداول في الحزمة المركزية `@djadwal/core` (عبر `print-header-generator`)، ونقل التوليد الثقيل إلى خدمة طباعة مخصصة تعمل في الخلفية عبر قائمة مهام مستقلة.

### الآثار الإيجابية (Positive Consequences)
- تحرير خادم الـ Express الرئيسي من أحمال المعالجة الثقيلة وتجنب الـ Event Loop blocking.
- توحيد جودة ملفات PDF الصادرة رسميًا للإدارة والأساتذة بجودة طباعة فيكتور عالية.
- إمكانية جدولة توليد جداول الأقسام ليلاً أو إرسالها آليًا عبر البريد الإلكتروني.

### الآثار السلبية والمخاطر (Negative Consequences / Trade-offs)
- الحاجة لإدارة خدمة مساعدة أو عامل مهام إضافي (Worker process).
- إدارة تخزين مؤقت للملفات المولدة (Object Storage / Temporary cache).

## 5. خطة التنفيذ والرجوع (Rollout & Rollback Strategy)
- الحفاظ على زر "الطباعة المباشرة من المتصفح" كخيار بديل فوري للمستخدم دائمًا.
- إتاحة زر "توليد PDF عالي الدقة" المتصل بالخدمة الجديدة خلف Feature Flag `ENABLE_HEADLESS_PRINT_SERVICE=false`.
- في حال تعطل خدمة الطباعة الخلفية، يعود النظام تلقائيًا لنمط الطباعة المحلي عبر نافذة المتصفح (`window.print()`).
