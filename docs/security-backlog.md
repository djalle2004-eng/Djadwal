# سجل المتابعة الأمنية ومكتبات الترقية المؤجلة (Security Backlog)

> **الميثاق الأمني:** عملاً بسياسة «لا شيء يُكسر»، يتم حجر المكتبات ذات الثغرات القديمة والمعروفة دون ترقيتها المباشرة في برومبت شبكة الأمان، لتجنب حدوث كسر في آليات معالجة الملفات (File Upload) وقراءة ملفات إكسل (Timetable Import) داخل النظام الحي.

---

## 1. حزمة Multer (`multer@1.4.5-lts.2`)

- **مستوى الخطورة:** High
- **نوع الثغرة:** DoS / Resource Exhaustion via Multipart parsing (CVE-2022-24434, CVE-2024-21528)
- **موقع الاستخدام الحالي:**
  - `server/server.js` لمعالجة رفع الصور والشعارات واستيراد الجداول.
- **سبب تأجيل الترقية:**
  - الترقية إلى `multer@2.x` أو `@fastify/busboy` تُغيّر الـ API والعقد البرمجي لمعالجة حقول الرفع المتعددة، مما قد يوقف رفع ملفات جداول التوقيت والنسخ الاحتياطي في الإنتاج.
- **خطة المعالجة المستهدفة:**
  - إنشاء مسار وسيط (Adapter) يدعم العقدين معًا في برومبت تحسين الـ Backend.
  - إضافة فحوصات لحدود حجم الملف (file size limits) ونوع MIME بشكل مسبق قبل التمرير إلى multer.
- **الهدف للإصدار القادم:** استبدالها بـ `@koa/multer` أو `busboy` المحدّث خلف Feature Flag `ENABLE_SECURE_FILE_UPLOAD`.

---

## 2. حزمة SheetJS (`xlsx@0.18.5`)

- **مستوى الخطورة:** High / Critical
- **نوع الثغرة:** Prototype Pollution in SheetJS (CVE-2023-30533, CVE-2024-22363)
- **موقع الاستخدام الحالي:**
  - `src/components/`, `server/routes.js` لقراءة ملفات Excel لجداول التوقيت وقوائم الأساتذة والأفواج.
- **سبب تأجيل الترقية:**
  - حزم `xlsx` الحديثة تم نقلها خارج سجل npm العام إلى مستودع SheetJS الخاص (CDN)، واستبدالها بحزمة بديلة مثل `exceljs` يتطلب إعادة كتابة كاملة لمنطق تحويل الجداول (Matrix cells to Timetable slots).
- **خطة المعالجة المستهدفة:**
  - اعتماد مكتبة `exceljs` في الحزمة المركزية `@djadwal/core` مع عزل التحويل في دالة مفحوصة بوحدات اختبار Vitest شاملة.
  - التحقق الصارم من مدخلات خلايا الملف ومنع حقول `__proto__` و`constructor` عند الاستيراد.
- **الهدف للإصدار القادم:** ترحيل المعالجة إلى `exceljs` مع الحفاظ التام على نموذج بيانات الجداول.
